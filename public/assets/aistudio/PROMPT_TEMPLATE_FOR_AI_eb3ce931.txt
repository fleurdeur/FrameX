### 1. WHAT A .KFPACK IS:
A `.kfpack` is a ZIP archive containing JSON metadata and GLSL fragment shaders.
The folder structure inside the ZIP MUST be:

my_pack.kfpack (ZIP)
├── suite.json
└── effects/
    └── <effect_id>/
        ├── effect.json
        └── shader.glsl  (or pass1.glsl, pass2.glsl if multi-pass)

### 2. NEW CAPABILITIES IN KEYFLAW 1.4.9+ (USE WHEN APPLICABLE):
1. Multi-Pass Shaders:
   In `effect.json`, specify `"passes": ["pass1.glsl", "pass2.glsl"]` for separable blurs, blooms, or downsampling.
2. Bounding Box Padding:
   In `effect.json`, specify `"expandBounds": 0.3` (30% padding) for glows, rays, and drop shadows so light does not get clipped at clip edges.
3. Smooth Directional Motion Trails (Zero Choppiness):
   For movement/shake shaders, include `"usesNativeMotionBlur": true`, a "Motion Blur" BOOL switch, a "Motion Trail Length" slider, and 20-tap stratified blue-noise dithered sub-frame integration in the GLSL code.

### 3. GLSL SHADER SPECIFICATION (OpenGL ES 2.0 / 3.0):
- Coordinate convention: `vTex` is normalized `vec2(0.0, 0.0)` (bottom-left) to `vec2(1.0, 1.0)` (top-right).
- Built-in uniforms automatically supplied by Keyflaw:
    uniform sampler2D uTexture;
    varying vec2 vTex;
    uniform float uTime;
    uniform vec2 uTexelSize; // (1.0 / width, 1.0 / height)
- Parameter uniforms: Keyflaw maps each slider in `effect.json` to `u` + Capitalized key name:
    key: "amplitude"  -> uniform float uAmplitude;
    key: "glowColor"  -> uniform vec3  uGlowColor;   (for type: "COLOR")
    key: "tileEdges"  -> uniform float uTileEdges;   (for type: "BOOL")

### 4. VALID KEYFLAW CATEGORIES:
